## 单条内容的编辑流程

1. 实际读取公开正文或素材详情页，核对永久链接、作者/机构和具体许可。搜索结果、标题或 HTTP 200 不能替代证据。
2. 记录读取日期与内部证据；未知原始发布日期不补造，核验日期不冒充发表日期。
3. 知识卡用中文独立归纳一个问题，保留适用条件，不逐段翻译整篇文章，不搬用原站图片。健康内容不添加来源未支持的诊断、剂量或疗效。
4. 媒体先确认许可再下载、解码和目视复核。按原始文件地址与 SHA-256 去重，再排除近似连拍、示意图、主体不清等不适合的素材。合法许可不自动等于画面合适。
5. 配文只描述可见画面或可靠来源支持的事实，可以自然邀请交流；不编造宠物姓名、主人经历、所在地、年龄、性别、健康状态或互动热度。
6. 视频检查实际选用的片段、封面和编码，记录截取与静音处理。没有音轨的成片不写成“听见叫声”；检查和播放是不同验收项目。
7. 选择圈子、主题、动物标签和内容账号，完成审核后再填 `review.status: approved`，不为通过校验预先批准。
8. 把合格记录放入完整清单，运行校验和构建，再在页面检查显示与筛选。导入命令与字段见 [250 条执行计划](09-首批300条内容执行计划.md)。

## 后续维护与部署边界

来源变化、内容过时或用户反馈错误时，重新核对证据并修订或撤下；不能只更换一个未经核验的链接。图片和视频地址失效时，先核对可用性和许可，再替换托管地址。真实活动必须核实主办方、时间、地点和报名权限；商家、订单和评论不属于本轮资料采集范围。

当前目录只接入本机演示服务，没有自动导入真实云数据库。发布微信前需验证合法域名、存储规则、真机加载、视频播放和多人操作。

预置短视频与用户上传分别管理：本机用户视频可保存和播放，但不代表通过云端审核。真实用户视频默认禁用，须接入完整视频及音轨审核 provider；`imgSecCheck` 或抽帧图片审核不能充当完整视频审核。配置及不确定结论均失败关闭，见 [视频上传说明](video-upload.md)。
