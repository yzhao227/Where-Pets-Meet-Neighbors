# 消息与社交功能验收

更新日期：2026-09-30。当前默认本机数据模式；云服务尚未部署，本记录不代表上线或微信真机验收。

## 本轮实现

- 消息页顶部使用自定义导航，标题为 40rpx，按状态栏和微信胶囊位置计算高度；页面内不重复显示标题。
- 搜索覆盖通知标题、正文、发送者公开昵称，以及本人有权访问的会话名、成员公开昵称和聊天文字。服务先筛选再分页，未读数不受搜索条件影响。
- 好友支持昵称或完整 ID 搜索、申请说明、接收方同意/拒绝、移除好友。好友关系独立于关注关系；资料未公开的陌生帐号仅支持完整 ID 查找。
- 已确认好友可发起私聊，或选择 1–19 位好友创建含自己在内 2–20 人的群聊。
- 聊天支持文字发送、失败重试、按序号分页、未读、成员查看和退出群聊。前台每 5 秒同步，隐藏或关闭页面后停止轮询。
- 圈子广场使用已有真实圈子，进入详情沿用已有加入/退出流程。

## 数据与访问规则

本机服务保留原存储命名空间，仅补充缺失的社交数据字段。没有向用户设备写入测试联系人或测试聊天。

建群和发信使用幂等请求编号。云端通过事务分配消息序号，好友与会话成员绑定帐号生命周期；非成员不能读取或发送。已读只推进至客户端实际获得的消息序号。屏蔽会解除好友、取消申请并隐藏相关消息；解除屏蔽不会自动恢复好友。注销会清理关系、成员资格和本人聊天内容。

新增社交写入沿用帐号核验，云端还执行内容审核与频率限制。退出、拒绝、解除关系及查看已有历史等操作保留恢复路径。

社交页面位于 `social` 分包。云端新增 `friend_requests`、`friendships`、`conversations`、`chat_messages`、`chat_reads` 五个集合，两份数据库结构清单保持一致。
