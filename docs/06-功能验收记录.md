## 本轮功能

| 模块 | 已实现与本地验证 |
| --- | --- |
| 圈子与话题 | 8 个圈子、8 个跨圈子主题；重复旧话题做兼容映射；话题选填并默认收起；圈子入口改为两列目录 |

| 视频投稿 | 照片最多 3 张，或 1 段视频；视频限 60 秒、20 MiB；选择、压缩、真实字节检查、持久保存、进度、失败重试与账号隔离 |
| 草稿恢复 | 图片和视频发生冲突时保留正文及两类附件，分别提供移除入口，提交前明确提示；不清空整份草稿 |
| 视频展示 | 列表播放标记、时长；详情原生播放器，手动播放、出错重试和离页暂停；真人视频不会被误判为整理内容 |
| 内容迁移 | 仅更新目录管理内容；保留用户自建帖子、昵称、资料、互动、私有草稿与上传记录；已撤下内容不被重新引入 |
| 内容展示 | 自然昵称；前台不显示作品来源、作者或许可面板；新素材均为 CC0/公有领域，证据内部保留 |
