# 有宠有邻 · 初版使用与接入指南

当前 v0.4 包含原生小程序、云端业务、数据库初始化与部署工具。现在可以先用浏览器体验社区流程，不需要微信小程序账号；默认只显示当前设备的用户内容，不再预填虚构社区数据。项目已配置真实 AppID，并完成官方模板与样式离线编译；云环境、完整模拟器操作及微信多人验收仍待接入完成。

## 一、打开体验

当前电脑的预览服务启动后，打开 **[有宠有邻本机体验](http://127.0.0.1:4173)**。已打开旧页面时刷新即可载入新版，已有的本机内容和报名仍保留。

如果链接打不开，在项目文件夹中打开终端，运行：

```sh
npm run dev
```

运行与测试需要 Node.js 22.13 或更新版本（推荐 24），无需先安装项目依赖。保持该终端打开。预览地址只在这台电脑上有效，不能把它发给朋友当作已上线的小程序入口。

本次 v0.4 增加发布草稿恢复、异步图片审核、正式政策配置、运行状态及部署基础，共 18 个页面。自动检查的最终结果见项目 README。浏览器验收启动此前被自动审批服务的配置错误阻断，尚未完成新版的视觉与浏览器操作验收。你可以手动打开上述本机链接体验。它与微信真机测试是两项独立检查，都不应当作已经完成。

## 二、建议按这个顺序试用

1. **发现感兴趣的内容。** 在「社区」浏览图文，按话题筛选，或搜索“散步”“咖啡”等标题、正文中的关键词。空结果时可清除搜索或切换话题。
2. **模拟加入与互动。** 首次点赞、收藏、关注等操作会进入加入页面。阅读协议和隐私说明，主动勾选后点击模拟核验按钮；不需要提供真实手机号。返回后重新确认原操作。给喜欢的内容点赞、收藏；点击作者查看公开帖子并关注，再到「关注」看该作者的更新。在「我」可以找到自己的收藏和关注列表。它们都支持取消。
3. **介绍自己。** 在「我 → 编辑」填写昵称和一句介绍。可以填写宠物，也可以选择「暂不填写」。主页公开开关默认关闭；你可以主动开启，让同好在你的主页看到介绍和宠物资料。另有独立的“头像旁展示宠物”选项，开启并保存后，在帖子和评论的署名旁显示宠物名字与类型；旧资料不会自动开启。
4. **加入圈子并发布。** 加入一个喜欢的圈子，发布日常、求助或邀约。标题选填，可添加最多 3 张图片并选择封面，勾选最多 3 个话题，也可关联已有活动。未发布的草稿按账号保存在本机，重新进入可恢复。真实模式会保留审核中和失败的图片状态，完成审核后才能发布，也可以移除后继续。发布后可以评论、回复或删除自己的内容。
5. **从帖子参加活动。** 打开关联活动的帖子，进入活动详情查看带宠要求、时间地点和名额，体验报名和取消。也可以直接从「附近」找活动。新安装不会提供虚构活动；管理员可先创建本机测试活动检查流程，本机记录不代表真实预约。
6. **查看消息与运营工具。** 「消息」显示站内通知，点赞和关注不会制造他人回复。当前本机身份拥有管理权限，可在「我 → 活动管理」创建/编辑/取消活动，在「我 → 举报处理」核查并记录举报结果，在「我 → 宠物资料统计」查看猫、狗等资料份数。「我 → 运行状态」可查看云端配置、待处理记录和最近维护；本机演示明确显示未连接云端。统计仅包括当前账号记录，未填写不等于没有宠物。

举报的「标记已处理」用于记录结论，不会自动删除原内容。需要删除时，先进入原内容完成治理，再记录处理结果。

## 三、当前版本的使用边界

| 项目 | 当前情况 |
| --- | --- |
| 数据保存 | 只保存在当前设备/浏览器。换浏览器、无痕访问或清除网站数据，会得到独立或重置后的体验 |
| 身份核验 | 本机仅模拟核验，不采集真实手机号；正式微信核验仍待 AppID、能力配置及真机验证 |
| 宠物资料 | 每个账号最多登记一只；主页公开与头像旁展示分别设置，默认关闭 |
| 图片 | 本机选择和保存，可用于图文发布；受浏览器/设备存储空间限制 |
| 附近 | 展示活动的片区与公共地点，未接入实时定位、地图或距离排序 |
| 交友 | 通过作者主页、关注、圈子、评论和活动建立联系；没有独立的一对一聊天功能 |
| 发现与搜索 | 根据所选话题、圈子、关注关系和关键词筛选内容，当前没有个性化推荐算法 |
| 通知 | 小程序内消息列表，没有微信订阅消息或手机系统推送 |
| 管理身份 | 本机体验默认可管理；真实模式必须由后端指定管理员 |
| 收费 | 活动免费；商家入驻、服务订单、商品交易和支付按后续里程碑推进 |

昵称、头像和已发布的公开帖子可在作者主页查看。自我介绍和宠物资料需要本人主动选择公开范围，头像旁展示单独控制；旧版资料不会自动扩大公开范围；片区始终不在公共主页展示。收藏列表只对本人可见。可在「我 → 清除我的资料和内容」清除自己的内容、资料与报名关系；同时会清除本机旧示例归档中的历史互动。

## 四、后面怎样让朋友真正使用

以下步骤需要你的小程序账号，当前尚未执行：

1. **取得自己的 AppID。** 申请微信小程序账号，并根据实际主体和服务内容完成必要设置。
2. **导入并检查小程序。** 用微信开发者工具导入项目根目录，替换 AppID，先保持本机模式检查页面，再做微信真机测试。当前已有业务与页面逻辑自动检查，新版浏览器验收受环境阻断，真实微信编译/真机验证也尚未进行。
3. **接入微信云开发与核验。** 按 [部署基础说明](../infra/README.md) 填写本机部署配置、生成候选包并运行候选包检查。创建云环境、部署后端，用受保护的初始化工具创建 20 个空集合，再配置并验证数据库权限、索引和存储隔离。配置真实手机号能力、服务端密钥以及实际运营主体、联系方式、保存期限、正式政策与平台隐私设置。正式政策或核验配置未完成时，互动功能会保持受限。配置服务端维护调度、备份和预算告警，再切换真实模式；没有云端接入时，朋友之间的数据不会互通。
4. **设置真实社区。** 指定你的管理员身份，在活动管理中设置真实城市、片区和运营联系方式，创建第一场真实活动。云端不会继承本机的用户资料、内容、活动或管理员身份。
5. **验证多人使用。** 用两个普通微信账号和一个管理员账号验证手机号授权成功/取消/失败、重复绑定、公共页面不泄露号码、宠物可见范围、发帖与回复、报名/取消、活动变更通知、举报处理及权限，另验收图片审核等待/拒绝/恢复、注销和维护重试。`scripts/wechat-smoke.js` 可辅助真实账号之间的发帖、评论、通知及测试数据清理。通过后再选为微信体验版。
6. **邀请第一批朋友。** 分享自己的微信体验入口，收集他们在发第一条内容、回复他人和参与活动时遇到的问题。正式公开发布还需完成平台要求的相关配置与审核。

云端文字发布接入微信内容检查。**云端图片上传默认关闭**。同步与异步图片审核源码均已实现，但需确认账号可用接口、实际云存储权限；异步模式还需配置加密回调并验证微信真实投递后才能开启。真实审核或存储配置失败时不会放行图片。这个限制不影响当前本机图片体验。

注册与资料规则见 [注册与资料可见范围](05-注册与资料可见范围.md)。具体操作和核验事项见 [云开发接入说明](../cloudfunctions/community/README.md)。AppID、云环境等配置接入后仍应以实际微信环境的验证结果为准。

## 五、后续迭代怎么判断

这一版先观察：新用户是否愿意介绍自己、是否得到真实回复、是否回来继续交流、活动是否有人实际参加。

你后续通过朋友圈、熟人、公园和微信群邀请的用户反馈，可以帮助决定先优化圈子与活动，还是引入商家。完整的服务、商店和变现节奏保留在 [里程碑落地计划](02-里程碑落地计划.md) 中，不需要为第一版一次做完。
