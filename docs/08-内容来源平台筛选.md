# 有宠有邻 · 内容来源平台筛选

更新日期：2026-09-29。本文件记录选材依据；实际采用条目以完整内容清单和 `npm run content:status` 为准。

## 本轮选择

本轮已完成 **50 条知识卡 + 197 条图片内容 + 3 条视频，共 250 条** 的构建与本机导入。图片中猫、狗各 50 条，另外 97 条用于其他动物；视频为兔子、鸟和寄居蟹，不再继续增加猫狗图片数量。知识卡复用合适的已核验照片作封面，封面不另计为一条图片内容。

文字采用已读取并核验的 ASPCA 资料作事实来源，独立撰写中文摘要。媒体采用 Wikimedia Commons 上逐项核实的 CC0/Public Domain 文件，包括知识卡配图、照片、视频和视频封面。不能仅凭“来自 Commons”认定可用，也不把媒体许可扩大成整篇来源文章的转载许可。

本轮不要求在普通页面公开摄影署名，原始出处、作者和许可证据继续保留。清单的 `omitPublicAttribution: true` 会限制媒体为 CC0/Public Domain；其他许可即使允许使用，也不能混入本轮免署名目录。

## 素材选择标准

先核对许可，再判断画面是否适合社区。优先清晰实拍、可辨认的动作、不同动物与生活场景；不为了凑数采用密集近似连拍、雕塑、插画、组织切片或骨骼标本。公开库中的搜索结果也可能与关键词无关。

猫狗照片按主体、场景和文件摘要去重；其他动物分散到小宠、鸟、水族及异宠圈子，减少信息流连续出现同一类画面。精选视频选用实际复核的片段，保留原视频、转码文件、封面和处理说明。当前采用兔子、鸟、寄居蟹，鱼群与群养仓鼠候选不因曾下载就自动计入最终目录。

配文可自然引导交流，但只描述画面和可靠来源支持的事实。不把拍摄者的宠物写成内容账号的宠物，不编造位置、年龄、性别、病情、照护经历或真实用户互动。静音视频不描述不存在的声音。

## 分类与免署名条件

8 个圈子组织社群，8 个主题描述内容；动物另用 `animalTypes` 标注，避免圈子、主题和物种三个筛选层重复。

主题为饮食喂养、行为观察、健康护理、居家布置、户外出行、成长记录、治愈瞬间、陪伴日常。猫狗同框标注两个动物类型；寄居蟹使用 `invertebrate`，可放水族日记。动物隐藏按已标注种类过滤，不能只靠圈子名称猜测。

CC0/PD 媒体不要求公开署名，因此页面不再堆叠来源标签。内部仍保存来源 URL、作者、许可页面、文件摘要及复核记录；旧 CC BY/CC BY-SA 素材撤下后仍保留原许可，不能删除署名后重新混入免署名批次。

## 核验与交付

1. 读取真实公开正文或文件详情，遵守站点访问规则、429 限流及重试间隔。
2. 保存原始资料、真实媒体和许可元数据；知识事实与图片/视频授权分别核对。
3. 下载、解码、查重并目视检查；记录通过与排除结果。自动程序不替代版权依据和内容判断。
4. 写原创摘要、客观画面描述，填圈子、主题、动物标签和自然昵称账号。
5. 实际审核通过后加入 `approved.json` 的完整快照；新旧清单与撤下项留档。
6. 运行 `content:validate`、`content:status`，按 `manifest.targets` 决定完整构建或小批发布。随后检查列表、详情、过滤、分页、封面和视频播放。

本机目录构建不等于微信发布。云环境未配置、云端内容尚未导入，合法域名和真机媒体加载仍待实际验证。用户视频云上传另需完整视频及音轨审核 provider，当前默认禁用；本轮预置视频不会自动开启该能力。
