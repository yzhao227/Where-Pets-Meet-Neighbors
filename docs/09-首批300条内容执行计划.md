## 内容和许可要求

知识卡依据已实际读取的 ASPCA 正文独立整理，保留原文链接、机构、核验日期和内部证据。健康、饮食、行为内容保留适用条件；不把国外地区的制度或活动直接写成中国要求。

本轮所有媒体，包括知识卡配图、照片、视频和封面，只采用逐项核实的 **CC0 或 Public Domain**。页面不公开堆叠来源、摄影作者和许可标签，内部继续保存作者、来源页面、许可链接、下载文件、摘要及修改说明。`omitPublicAttribution: true` 会使校验拒绝不满足此条件的媒体；该标志不会赋予额外使用权。

原 CC BY/CC BY-SA 素材已经退出本轮选材范围，其文件和许可证据保留作历史材料。无需公开署名不等于可冒充摄影作者；配文不编造昵称账号的个人经历、宠物姓名、所在地、真实身份或互动。

图片使用已核验的公开 HTTPS 托管地址或真实 `cloud://` 文件地址，不把全部原始照片嵌入主包。打包预置视频只允许 `/assets/curated-video/数字.mp4`，必须对应真实文件并匹配 SHA-256；每条须满足工具规定的文件大小上限。实际微信包体以开发者工具检查为准，不在本文写死估计值。

## 导入命令

在项目根目录运行：

```sh
npm run content:status
npm run content:validate
```

`status` 返回实际 `targets`、`counts`、`approved`、错误列表及就绪状态：

- `metadataValid`：当前条目通过字段、枚举、重复和相关文件校验。
- `readyToBuild`：每类实际数量和审核通过数量均等于清单目标。
- `readyToBuildPartial`：非空清单全部审核通过，且每类数量不超过目标。

工具不会自行读取原网页、确认版权或代替内容编辑审核。`review.status: approved` 必须来自已经完成的实际核验。

完整达到本轮配额时运行：

```sh
npm run content:build
```

若需要先发布已经审核的小批内容，可运行：

```sh
npm run content:publish
```

两种命令都先校验，再原子替换运行目录。**输入必须是想保留的全部目录内容的完整快照，不是只含新增条目的增量文件。** 未列入的旧目录项会撤下；空清单或不合格清单不会覆盖当前目录。其他清单可在命令后通过 `-- 路径` 指定。

这两个命令只写本机 `curated.js`，名称中的 publish 不代表已向微信上传、提审或发布。

## 成文记录字段

| 字段 | 要求 |
| --- | --- |
| `id` | 稳定唯一；知识为 `knowledge-*`（兼容 `guide-*`），图片为 `photo-*`，视频为 `video-*` |
| `contentType` | `knowledge`、`photo` 或 `video` |
| `title` | 原创中文标题，1–40 字 |
| `text` | 独立正文或客观说明；知识至少 60 个非空白字符，最多 1000 字；媒体说明 1–1000 字 |
| `topics` | 最多 3 个有效主题，归一化后去重 |
| `circleId` | 项目当前圈子 ID |
| `animalTypes` | 最多 3 个有效动物种类，忠实于知识对象或画面 |
| `editorId` | 上表中的内容账号 ID |
| `source` | 原始标题、机构、作者、实际核验的 HTTPS 来源地址与核验日期 |
| `review` | 实际审核状态；通过时补充审核人及日期 |
| `images` | 逐图元数据数组；知识 0–3 张、图片内容 1–3 张、视频恰好 1 张封面 |
| `coverPhotoId` | 知识卡可引用清单中已核验图片的 ID；不能同时自带 `images` |
| `video` | 仅视频条目提供，保存视频地址、封面、时长与来源许可等元数据 |

媒体对象须保留 `url`、`originalUrl`、`sourceUrl`、`author`、`license.name`、`license.url`、`attribution`；改动放在 `modifiedDescription`。即使前台不显示署名，编辑清单仍保存完整出处。

`contentHash` 保存实际文件的 64 位十六进制 SHA-256，可带 `sha256:` 前缀。工具按原始 URL 与摘要查重；编辑还需目视排除同场景近似帧。知识卡通过 `coverPhotoId` 复用资产，不重复创建一条照片，也不能借此绕过许可校验。

视频的 `poster` 必须与该条目唯一的已核验 `images` 封面一致，时长须在 1–60 秒。截取起止、转码、静音等变更据实记录，预置片段仍保留原视频来源。内部证据通过审核材料和可选 `permissionRef` 追溯，不在字段中放账号密钥、访问凭据或私人协议全文。
