## 导航在不同环境中的行为

| 情况 | 行为 |
| --- | --- |
| 已有可靠 GCJ-02 坐标 | 调用微信 `wx.openLocation`；浏览器预览直接打开腾讯地图地点标注 |
| 浏览器预览中只有公开地址 | 直接进入腾讯地图城市内的地点搜索；保留真实地点名称，用户选择匹配的目的地和入口 |
| 云端已配置、公开记录缺坐标 | `getPlaceNavigation({id})` 读取服务端记录，解析公开地址，再调用 `wx.openLocation` |
| 只有地址但云端未配置，或无法可靠解析 | 显示暂不可用；不复制地址、不虚构坐标、不自动获取用户位置 |
| 地点尚未公布 | 不启用导航 |

导航仅使用目的地，不发送用户住宅、当前位置或私人资料。地图中的路线和入口选择由地图产品提供；场所坐标不等同于宠物区入口。

## 开通微信端地址解析

1. 按 [云开发后端说明](../cloudfunctions/community/README.md) 完成 `community` 云函数、数据库及规则配置。
2. 在腾讯位置服务控制台申请可调用 WebService 地址解析的 Key，按实际用途配置调用权限与配额。
3. **只在 `community` 云函数的环境变量中**设置 `TENCENT_MAP_KEY`，重新部署云函数。不要写入小程序 `config.js`、源码或聊天消息。
4. 客户端使用真实 `cloudEnv` 和 `mode: 'cloud'`。当前本地配置仍为演示模式，未填写云环境。
5. 微信真机验证已有坐标地点、仅地址地点、未配置/无可靠结果及退出页面后迟到响应。

服务端返回 `{point, name, address, resolvedFrom}`，`point` 明确为 GCJ-02；仅接受公开地点 ID，不接受客户端任意地址。解析须同时满足可信度至少 7、精度至少 9、城市匹配，不把区或道路中心当成目的地。每账号每分钟最多 20 次解析请求，已有坐标不占此额度；成功解析短暂缓存在云函数内存，不改写目录。请求有超时和响应大小上限，解析完成后再次确认账号及地点未变更或下架。

## 微信端原文打开范围

- 普通公众号文章：基础库 3.4.8 起提供 `wx.openOfficialAccountArticle`，需用户点击触发；无效、临时或异常文章不保证可打开。
- 普通网页：需要支持 `web-view` 的主体，并实际验证业务域名。官方文档明确**个人类型小程序暂不支持 `web-view`**。第三方政府、媒体网站不能只把域名填进配置就获得权限。
- `config.js` 的 `publicWeb` 默认关闭。仅在实际通过微信业务域名配置后启用，并列出精确主机名；发布配置支持同名可选字段。
- 微信端不能打开的外链不提供直接跳转；标题旁「查看原文」按钮改为展示信息弹窗，其余来源区保留文字网址。浏览器预览可以直接打开安全的 HTTPS 原文，不能据此宣称微信端所有第三方网页都已可跳转。
