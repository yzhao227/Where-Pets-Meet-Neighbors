# 有宠有邻：上海闵行个体工商户与小程序备案申请指引

核对日期：2026-09-30。适用情况：申请人有上海闵行区自有房屋，产权用途为“居住／住宅”；目前小程序为个人主体且备案被驳回，拟运营宠物兴趣内容社区。

公开规则支持将个体工商户作为申请主体的路径：微信将个体工商户纳入注册时的“企业类型”，“社交—社区／论坛”向非个人主体开放。具体以申请时后台可选类目、材料要求及审核结果为准。

建议顺序：确认经营地址 → 个体工商户设立登记 → 领取执照、刻章 → 核对并办理现有小程序主体变更 → 使用新主体办理小程序备案 → 完成社区类目资质申请 → 提交代码审核、发布。

## 1. 先确认自有房屋能否用作经营场所

你已确认产权用途为“居住／住宅”。第一步应先核对住宅改变用途手续，不能直接把自有住宅填成普通办公经营场所。

| 房屋情况 | 办理方式 |
| --- | --- |
| 非居住用房，如符合用途要求的办公、商业用房 | 可以作为经营场所候选。自有房屋准备不动产权证，地址按产权资料填写；仍须满足房屋用途及登记条件。 |
| 普通城镇住宅／居住用房 | 上海现行办法要求办理改变房屋使用性质的手续。自有房产证、业主签字或物业口头同意，都不能当然替代这些手续。 |
| 农村宅基地房屋 | 另有房屋安全鉴定、利害关系人同意及街镇证明要求，不按普通商品住宅处理。 |

依据：《上海市经营主体住所登记管理办法》第七、九条，以及《上海市闵行区经营主体住所登记管理实施细则》第七、十条。闵行细则自2024年11月25日起施行，有效期至2029年11月24日。

先向闵行区市场监管登记窗口及房屋管理部门确认可否依法改变用途、具体手续和材料。若不适合办理，再考虑具备合法使用权、用途合规且能办理个体户登记的非居住经营场所。不要先购买地址服务。

闵行区该登记事项官方咨询电话：**021-33885338**。办事指南将境内自然人的线下办理点列为闵行区各市场监管所；可先用该电话确认房屋所在街镇的受理所，不要直接按台港澳自然人的受理地点跑窗口。

上海允许的“个体工商户登记地”主要面向社区内从事居民服务业的个体户，不能直接认定宠物互联网内容社区符合条件；“企业集中登记地”也不能当然用于个体户。需要按所在区规则核对。

“网络经营场所登记”适用于仅通过网络交易平台开展网络交易活动的平台内经营者。运营自有内容社区小程序，并不当然符合这一条件。

地址咨询时可以这样说明：

> 我在闵行区有自有住宅，准备登记个体工商户，运营宠物兴趣内容社区小程序，提供用户发帖和互动，暂不提供商品交易及支付。根据闵府规发〔2024〕10号第七条，住宅需要办理改变使用性质手续。请确认我所在街镇应向哪个部门申请、需要哪些材料，以及这类互联网社区业务能否适用本区个体工商户登记地？

无需在普通咨询中发送完整身份证号或产权证照片；正式材料只在官方办理渠道按要求提交。

## 2. 准备个体工商户设立登记资料

官方入口：[闵行区个体工商户设立登记注册](https://zwdt.sh.gov.cn/govPortals/bsfw/item/d1fbe863-a543-4914-b170-20246b53d47c)，点击“立即办理”；也可从[上海企业登记在线](https://yct.sh.gov.cn/portal_yct/)进入。若最终改用其他区经营场所，应选择实际场所所在区。

基本准备项：

- 经营者本人身份证、本人手机号及可使用的实名“随申办／一网通办”账号。
- 经营者住所相关文件，按所选区办事指南要求准备；这与“经营场所使用证明”是不同材料。
- 合规经营场所证明：自有房屋通常为不动产权证；租赁房屋通常为不动产权证和租赁合同；住宅另需符合第一步的要求。
- 拟用字号及备选字号。可先用“有宠有邻”作为字号候选，完整名称由登记系统结合区划、行业及组织形式生成并审核。
- 实际经营范围、组成形式等信息。若确为本人独立经营，选择与事实一致的个人经营；不要把家庭经营、合伙或公司选项混用。
- 《个体工商户登记（备案）申请书》，使用系统生成的文书或官方表格。
- 如委托他人办理，准备系统要求的委托及经办人材料；如有登记前置审批项目，补充相应批准文件。

经营范围不要直接照抄宠物店、电商店模板。向登记窗口或系统咨询提交以下业务描述：

> 运营自有宠物兴趣内容社区小程序，面向养宠及爱宠人士，提供用户发布宠物日常内容、评论交流、关注收藏、兴趣圈子和活动信息等服务，首版不提供商品交易、平台付费服务及支付。

可以在规范经营范围库中核对与实际工作相符的“软件开发”“网络技术服务”“数字内容制作服务（不含出版发行）”等项目，但这些候选项目不代表已确认能完整覆盖面向公众运营互联网社区。应同时让登记窗口核对主营社区业务的规范项目及是否涉及许可。若某项被列为许可项目，登记在执照上不代表已经取得许可，也不能仅为减少材料而删去真实业务。

## 3. 在线提交、领照及刻章

1. 进入“上海企业登记在线”的开办入口，或一网通办对应区的个体工商户设立登记事项。
2. 按提示以经营者实名账号登录，选择个体工商户及经营场所所在区。
3. 填写名称、经营者、经营场所、组成形式、经营范围及系统要求的其他信息。
4. 上传或调用电子证照，检查系统生成的申请书；由本人完成实名核验及电子签署，再提交。
5. 查看预审／审核意见，按要求补正。获准后领取电子营业执照及按需领取纸质执照。
6. 办理合法刻章，准备后续小程序备案所需的公章；同步按税务系统要求办理相关信息确认，并确定后续申报安排。

闵行区一网通办设立登记事项标注“不收费”，并支持全程网办。材料齐全、符合法定形式可当场登记；不能当场登记的，一般在3个工作日内审查，复杂情形可再延长3个工作日。房屋手续、补正、证照领取等时间不包含在这一审查时限内。

**上海小程序备案须刻章。**微信《备案常见问答》明确：上海等地区不接受以负责人手印替代公章。这与小程序主体变更申请函的签字、公证规则是不同事项。

## 4. 处理现有个人小程序：优先核对“主体变更”

先保留当前账号、名称及项目数据。不要先注销，也不要误选两个账号之间的“账号迁移”。

官方路径：微信公众平台小程序后台 → 设置 → 基本信息 → 主体信息 → 小程序主体变更。

主要材料包括：原个人主体身份证明、新主体营业执照、主体变更申请函、目标主体所需的服务类目资质，以及后台要求的授权验证材料。目标主体按微信对应企业类型填写，执照名称、统一社会信用代码和经营者信息必须一致。

公证方面：官方对“原个人主体即目标企业类型主体法人”等情形提供免公证规则，但没有在这段条文中直接写明个体工商户经营者。可以按“原个人主体与新个体户经营者为同一人”提交免公证材料核验；不要提前认定一定免公证，也不要在查看后台要求前先付公证费。

### 支付主体变更费用前的检查点

主体变更流程要求选择目标主体服务类目并提交资质，而“社区／论坛”所需的新主体备案材料可能尚未取得。公开说明没有把“个人备案未成功 → 个体工商户社区”的材料衔接过程完整说明。

进入资料填写页面后，先确认社区类目的备案材料能否后补。若后台强制要求新主体已完成备案、无法继续，应让微信审核渠道明确办理顺序，再支付变更费。可直接使用以下问题：

> 我的个人小程序备案被驳回、尚未取得备案号，准备变更为本人经营的个体工商户，实际业务是宠物内容社区。目标类目为“社交—社区／论坛”，但新主体备案尚不能办理。请确认主体变更时是否可后补该备案材料，或应按何种官方顺序办理？

不要临时选择与实际社区功能不符的“图片处理”来跳过材料。

官方主体变更审核费为300元／次，提交后不论审核结果均不退；通常7个工作日内完成审核。通过后须按通知在7天内由管理员确认，重新登录并完成相关协议步骤。具体以付款页及通知为准。

若选择另注册企业类型小程序，则会获得新的AppID，现有登录标识、云环境关联和数据需要另外评估。该方案不是当前账号的自动无损升级，应在确认影响后再选。主体变更对现有云资源及用户数据的具体影响，也应在提交前核对，本文不作全量不变的保证。

## 5. 使用营业执照对应的主体办理小程序备案

入口：小程序后台 → 设置 → 小程序备案 → 去备案；未上架账号首页也可能展示备案入口。

你目前是个人备案被驳回、未成功取得备案号，不能套用“注销已有成功备案”的步骤。账号主体调整完成后，按后台生成的备案类型，以新主体重新填写／发起备案。若实际已有成功备案，则主办者或证件号码变化另有注销原备案、重新备案的规则。

准备材料：

- 个体工商户营业执照，名称、统一社会信用代码逐字一致。
- 主体负责人、小程序负责人身份证件及可联系的手机号、邮箱。
- 实际通讯地址及后台要求的相关信息。
- 公章，以及后台按实际情况生成的承诺、授权等文件。
- 按要求完成负责人身份及人脸核验。

服务内容按实际社区功能填写，重点匹配备案分类中的“休闲娱乐—网络社交”；宠物资讯等独立服务再按实际情况核对。备案服务内容分类与小程序服务类目不是同一张表。

以下备注仅适用于首版仍保留目前这些功能的情况，提交前应与最终上线版本核对：

> 有宠有邻提供宠物兴趣内容社区，面向养宠及爱宠人士，支持发布宠物日常图文及视频、交流养宠经验、评论回复、关注收藏、加入兴趣圈子、填写宠物资料及社区成员私信、群聊，并展示同城宠物活动信息、提供平台免费活动报名。首版不提供商品交易、平台付费服务和支付功能。

外部活动可能收费，因此这里没有把所有活动描述为免费。若首版实质删除或调整某项功能，备注也相应调整；不能只在备注中省略实际上线的功能。

备案本身免费。官方参考时限为平台初审1—2个工作日、驳回修改再提交审核7个工作日、管局审核1—20个工作日。收到12381核验短信后，应在24小时内按官方要求完成核验。新执照遇到工商信息比对失败时，官方提示可能需要5—15个工作日同步，不要据此修改真实证照信息。

## 6. 申请社区类目及上线审核

1. 在后台服务类目管理处，按实际功能申请“社交—社区／论坛”；图文笔记分享、活动报名等是否需要补充类目，按实际页面及后台要求核对。
2. 提交与当前小程序及主办主体对应的《非经营性互联网信息服务备案核准》材料。微信官方示例为工信部备案系统中的小程序备案查询记录。
3. “社区／论坛”这一行未列必须取得经营性ICP许可证的要求，不能把备案材料和经营许可证混为一谈。私信、群聊是否需要增加其他类目，由实际场景决定；本指引不替全部聊天功能作准入承诺。
4. 核对名称、简介、备案备注、类目和实际功能一致；当前“工具—图片处理”不能继续作为社区功能的依据。
5. 完成隐私保护指引及实际内容审核、举报处理等上线准备，提交代码审核。该类目首次代码审核另有当地互联网主管机关审核确认环节，官方参考时长约7天。
6. 代码审核通过后再由管理员发布。备案通过、类目通过和代码审核通过是不同环节。

## 7. 费用和时间不要混算

| 项目 | 已核实情况 |
| --- | --- |
| 个体工商户设立登记 | 闵行区一网通办事项不收费；地址租赁、房屋手续、代办不属于该审批费。 |
| 刻章 | 上海小程序备案所需，费用按合法刻章服务报价核对。 |
| 现有小程序主体变更 | 官方审核服务费300元／次；先核对材料衔接再付款。 |
| 微信认证 | 与主体变更是不同事项，是否另需办理及费用按当前后台核对。个体户没有对公账户，可按官方指引采用微信认证方式完成注册认证。 |
| 小程序备案 | 免费；平台及管局审核时间另计。 |
| 公证、经营地址 | 取决于实际适用条件，不应预先视为固定必付套餐。 |

领照后即使尚未盈利，也应按要求办理税务申报和年度报告。按实际经营情况申报，不应默认都作零申报。
