# 附近投稿与审核

更新日期：2026-09-30。默认本机模式；云端上线仍需配置、部署与微信真机验收。

## 使用入口

- 用户：消息页右上角「＋ → 投稿」。可以推荐活动或好玩的公共地点，在「我的投稿」查看进度。
- 运营：「我的 → 管理工具 → 投稿审核」。入口只对管理员显示，服务端也会验证权限。
- 发布结果：审核通过的地点进入「附近」的地点列表，活动进入活动列表，并按现有日期筛选规则展示。

## 提交与审核

投稿包含名称、公开场所地址、城市、介绍，以及可选的片区、携宠说明、费用和参考链接。活动还需填写开始与结束日期。当前支持文字投稿，不采集联系人或住宅坐标，不自动获取定位。

提交成功后进入待审核状态。待审核、已拒绝或已撤回内容不进入公开目录。用户可以撤回尚未审核的投稿；被拒绝的投稿可修改后重新提交。

运营可以修改将要公开的资料，确认已核实后发布，也可以填写原因拒绝。已发布内容可以由运营下架。申请人身份和内部审核说明不写入公开地点资料。

审核通过是一次完整写入：同时更新投稿状态并生成唯一的公开记录。重复提交或重复点击不会重复发布。审核与用户撤回、注销并发时，以服务端重新检查的状态为准。

投稿人注销后，未发布的私有投稿会被删除；已发布内容仅保留匿名运营记录，移除账号、生命周期、原始请求及审核备注，运营仍可下架已发布活动或地点。重新注册不会重新取得旧投稿。

## 数据和运行方式

私有投稿保存在 `nearby_submissions`，公开审核结果保存在现有的 `place_records`。云端集合禁止客户端直接读写，通过现有服务进行核验、内容审核和权限检查。

本机模式只在当前设备内保存投稿和审核结果，不会发送给远程运营人员；切换到已配置的云环境并完成部署后，才能让不同设备上的用户和运营共用数据。

测试使用独立内存数据，不向真实本地预览写入虚构活动、地点或用户。

## 本轮验收

- 提交、查询、审核、撤回、下架均有服务与页面测试；覆盖普通用户越权、审核失败、幂等重试、状态竞态、双表回滚及注销后的匿名管理。
- 实际页面控制器调用本机服务，验证地点和活动发布后进入附近搜索与详情，下架后不再出现；待审核、已拒绝内容不公开。
- 浏览器独立内存沙盒已走通投稿人提交、运营编辑名称、确认核实后发布、附近搜索到修改后的内容。未向真实预览写入测试内容。
- 31 个页面的配置和脚本检查通过；微信官方离线编译通过 31 个 WXML 模板、32 份 WXSS。主包低于 2 MiB，投稿页面放在 `social` 分包。

这些结果不替代云部署、跨设备、微信键盘与真机验收。
