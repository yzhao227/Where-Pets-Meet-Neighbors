## 发现页与媒体

- 卡片标题 23rpx，作者及计数 20rpx；320px 窄屏分别为 11.5px 与 10px。标题下保留小号圈子与话题，搜索框最多 120px。
- 采用更高的固定封面，避免加载后跳动。320px 下首批 20 张卡片的图片占整卡高度约 68.5%–74%。常规比例铺满，极端比例保留完整图；详情可查看原图。
- 保留列表缩略图优先、按需加载、失败回退一次与手动重试。顶部下拉刷新、底部自动续载与封面等待缓冲继续生效。
- 多图详情支持原生 swiper、左右切换、缩略图、页码、原图预览与单张重试。旧请求回调不能覆盖当前图片状态。
- 视频显示原生播放、进度、静音和全屏控件；进入帖子后由用户点“播放视频”，再打开该视频所属的 media/media2/media3 分包播放器。微信端先将代码包 MP4 复制到用户文件路径，再挂载原生 video；复制失败可回退二进制读取/写入，重试会重新挂载，离页暂停并清理临时文件。旧视频 URL 仍兼容，远程视频保留原行内播放器。
- 微信原生播放器不再传入不支持的本地 poster 路径；封面保留在帖子播放入口。视频目录、列表海报和仅由分包引用的共享播放器脚本均明确列入打包保留项，检查脚本防止配置遗漏。
- 浏览器预览复用媒体节点，正确处理 autoplay=false 和多段文本插值；图片预览支持按钮、键盘及滑动。
- 本轮实际浏览器操作：原孔雀鱼、新增仓鼠视频分别通过播放入口进入 media/media3，均从 0 秒播放到 8 秒结束；原三图内容可切换至 2/3、3/3 并打开原图，新增美西螈组图可切至 2/2 并打开第二张原图。远程图片曾出现加载失败，界面显示单图重试；实际速度仍取决于网络与源站。
- 微信开发者工具模拟器曾实际显示修复后的孔雀鱼视频画面，但随后共享工作区保存触发了重新编译，未取得整段播放结束证据；手机播放尚未验收。

## 地点、收藏与到访

- 新增我的地点：收藏、私人到访日期/备注、纠错记录及管理入口。收藏兼容地点与外部活动资讯。
- 新增管理员地点管理：增改资料、上下架、处理纠错、将静态目录补入云库并保留运营修改。
- 完整软件流程为：地点详情 → 收藏或导航 → 记录到访 → 从到访发布 → 帖子关联公开地点。既有草稿保留，使用新地点需明确选择“改用刚才选择的地点”。
- 帖子详情和发现卡片展示关联地点；仅对有效公开场所坐标计算直线距离。私人到访备注和记录编号不会公开，拒绝定位仍可浏览。
- 已补客户端演示、云函数、目录快照、集合与索引定义；云端权限仍只允许通过服务端访问。账户注销、重复到访和并发清理有回归覆盖。
- 本轮浏览器核对了地点详情、收藏/到访/纠错入口及地点带入既有草稿的行为；未对真实用户发布帖子或创建到访记录。

## 宠物资料

- 最多 8 只宠物、10 类动物；支持名字、品种、生日或估计年龄及独立照片。
- 照片使用宠物专用上传票据与独立队列，沿用内容审核管线；通过审核且归属关联成功后才替换旧照片。发帖上传不能挪作宠物照片，宠物上传也不能挪作发帖。
