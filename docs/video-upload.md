# 视频上传与审核接入

## 预置短片与用户投稿

预置目录可以使用随小程序打包的 MP4 短片。导入器只接受 `/assets/curated-video/数字.mp4`，要求文件实际存在、解析后仍位于该目录、单条不超过 300 KiB，并与清单的 SHA-256 `contentHash` 一致。其他本地路径、查询参数、越界符号链接，以及把这个路径用于图片、视频封面或原始来源都不允许。封面仍使用清单中经过核对的公开 HTTPS 或云文件地址。

原始视频网页、作者、许可、审核记录和转码说明保留在素材清单；缩短或转码后的文件需要使用其自身的 SHA-256。启用 `omitPublicAttribution` 的批次只接受 CC0 或 Public Domain 视频与封面素材。导入器负责元数据、文件和配额校验，来源真实性、许可适用范围及内容本身仍需逐条人工核对。打包后还需检查整个小程序主包体积；单条达标并不代表总包达标。

这项打包路径例外只适用于运营预置内容。用户投稿不能提交任意本地路径或网络视频地址，必须使用本人上传并完成处理的票据。预置短片能播放，也不表示用户视频的云端审核已经启用。

## 用户视频与草稿恢复

客户端支持一篇分享选择一个视频，和照片互斥。微信原生选择与压缩后，按实际文件字节检查 20 MiB 上限，并检查 60 秒时长上限。文件先保存到本机，再申请云端上传票据。取消、断网和保存失败保留正文；成功保存的视频可在重启后继续上传。临时文件因微信清理而失效时，会保留失败记录并提示重新选择。

`uploadVideo(onProgress)` 的可选回调仅转发云上传任务提供的真实进度。`resumeUploads()` 返回 `{images, video, completed, pending, failures}`。视频完成后形如 `{url, durationSeconds, width?, height?}`；未完成的记录有 `mediaType: 'video'`，未经审核的云文件不会作为可发布视频返回。

本机演示模式只保存和播放本机文件，不代表云端内容审核通过。

恢复草稿时，如果照片与视频同时存在，两类附件都会保留并显示移除入口；页面会提示先选择一类，正文不会被清空，也不会自动发布。冲突解除后重新检查上传状态，不会静默删除用户选择保留的恢复附件。明确过期或未通过的票据仍不能发布，需移除或按提示重试。真实用户的视频保留发表时间，不会因为视频类型被当成运营资料。

动物隐藏偏好作用于社区推荐与关注流、圈子内容和作者主页，后端在分页前过滤，翻页保持同一偏好。更改偏好后，已发出的旧分页响应不能混入新列表。该设置按分享标注生效；没有标注的内容不会从作者宠物资料推断种类。我的已发布和收藏记录保留访问，打开详情仍可查看原文；偏好保存在当前设备。

## 云端启用条件

当前仓库没有配置真实视频审核供应商，生产入口默认关闭。微信的 `imgSecCheck` 和现有图片异步审核链路不会被当作视频审核。仅填写环境变量也不能开启视频。

运营方选定能审核完整视频及音轨的服务后，需要编写真实供应商适配器，并在 `cloudfunctions/community/index.js` 创建存储实例时注入：

```js
const storage = createStorage(cloud, process.env, {
  repository,
  videoReviewProvider
});
```

适配器接口为：

```js
{
  supportsFullVideo: true,
  supportsAudio: true,
  async review({ bytes, contentType, sha256, metadata, openid }) {
    // 将完整文件交给供应商并取得最终结论。
    // 成功返回 { decision: 'pass', sha256 }。
    // 明确违规返回 { decision: 'reject', sha256 }。
    // 未完成、无法确认或服务错误必须抛出异常；不得直接返回 pass。
  }
}
```

同时配置 `VIDEO_UPLOADS_ENABLED=true`、`VIDEO_REVIEW_MODE=provider` 和正确的 `CLOUD_FILE_PREFIX`。审核采用独立的同步等待链路，默认最多等待 60 秒，可由服务端 `videoReviewTimeoutMs` 配置在 1–90 秒内调整。适配器须在此期限内取得最终结论；若供应商只能提供更长时间的异步任务，应先接入持久异步状态机，不能提前视为通过。

服务端从收到的 MP4 字节读取盒结构、编码格式、视频轨道、时长、尺寸及样本表，并检查体积。当前接受普通 H.264/H.265 MP4；音频文件、改后缀文件、结构损坏、碎片化/加密或不支持的编码会被拒绝。结构检查不替代解码或内容审核。最终发布使用交给审核服务的同一份文件字节，审核结论需与其 SHA-256 一致；客户端提交的时长和尺寸不会覆盖服务端结果。

视频审核服务暂时不可用且尚未产生发布文件时，未过期票据恢复为待处理状态，保留归属和清理记录，重试会重新检查实际文件。明确拒绝、无效视频或超过限制会进入失败状态；客户端传入的通过标记无法改变结论。视频与图片不能混用发布票据，完成的视频票据也不能重复用于另一篇分享。

生产接入后仍需用真实微信账号验证供应商拒绝、超时、音轨违规、重复请求、账号切换，以及真机保存、播放和弱网恢复。
