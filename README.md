# 有宠有邻 · 喜欢宠物，就在这里相遇

以宠物为共同兴趣，让喜欢小动物的人慢慢认识彼此。养宠和暂时没养宠的人都可以参与。

当前为 **v0.4 部署基础版**，包含原生微信小程序、社区后端、数据库初始化与发布工具。默认使用本机数据服务。**AppID 已配置，云环境尚未配置，尚未部署或通过微信真机验收。**

当前本机目录共 **360 条内容：58 条知识卡、289 条图片内容、13 条短视频**，包括多图内容及多个动物种类。数量、审核状态与构建就绪情况以 `npm run content:status` 的实际输出为准；本机导入不代表微信云端发布。多图、视频和宠物资料能力见 [媒体地点与宠物资料验收](docs/13-媒体地点与宠物资料验收.md)。

附近页另有独立目录，当前含 **20 个地点、9 条展览和活动记录**，与社区内容分开维护。支持搜索、区域和玩法筛选、携宠规则、日期筛选、实景图、路线攻略、主动定位或手选参照，以及公共目的地导航。参考资料、携宠条件和时效说明在详情查看；缺少已核实坐标时不编造距离。运营审核通过的用户投稿也会进入对应列表，未审核内容不会公开。云环境尚未配置与部署。来源与导航边界见 [附近导航与原文跳转](docs/14-附近导航与原文跳转.md)。

## 现在就能体验

电脑安装 Node.js 22.13 或更新版本（推荐 24）后，在项目根目录运行：

```sh
npm run dev
```

打开 [有宠有邻本机体验](http://127.0.0.1:4173)。本机体验没有第三方依赖，不需要先运行 `npm install`。服务运行期间保持终端打开；按 `Ctrl+C` 停止服务。

浏览器体验使用小程序的页面逻辑、模板、样式和演示数据服务，方便检查页面与操作。微信原生选片、持久文件、上传进度和视频播放仍需在开发者工具与真机中验证。

附近宠友以宠物为主角，默认显示主动开放的宠物资料；未公开宠物的参与者放在“爱宠同好”，不推断其是否养宠。双方开启住宅距离后，只返回大致范围。已接入最多 8 只宠物的资料和独立照片流程；照片通过审核并确认归属后才替换旧图，公开展示仍遵循用户选择。操作与限制见 [附近宠友与住宅距离](docs/11-附近宠友与住宅距离.md) 和 [媒体地点与宠物资料验收](docs/13-媒体地点与宠物资料验收.md)。

宠物交友也通过圈子交流和线下活动展开。商家入驻、本地付费服务、商品交易及支付留在后续里程碑。

投稿入口位于「消息 → ＋ → 投稿」，管理员在「我的 → 管理工具 → 投稿审核」处理。文字资料通过审核后才显示到附近对应的地点或活动列表；本机模式仅保存当前设备上的投稿与审核记录，不会发送给远程运营人员。流程与数据边界见 [附近投稿与审核](docs/16-附近投稿与审核.md)。

外部展览与活动不创建站内报名、名额或付费订单。只有月份的官方预告不显示成已确定日期的近期活动；往期内容明确标记已结束。地点携宠条件未知时不进入“带宠出门”。实景图的来源与许可按图保留，需署名的素材在详情资料区展示；照片不代表当前入场规则或展讯。更多坐标、入口及信息时效仍需持续核实。

## 圈子、主题和动物筛选

8 个圈子用于组织社群：爱宠邻里、猫咪慢生活、汪星人日常、小宠乐园、羽毛朋友、水族日记、异宠观察、新手养宠。

8 个主题用于描述内容：饮食喂养、行为观察、健康护理、居家布置、户外出行、成长记录、治愈瞬间、陪伴日常。主题不再重复“猫”“狗”等圈子或动物名称；旧主题会映射到当前值并去重。

动物标签独立于圈子和主题。用户可只看某类动物，也可隐藏不想看的种类；未标注内容单独提供入口。猫狗同框应同时标注猫、狗，隐藏其中任一类会排除该内容。寄居蟹使用 `invertebrate`（无脊椎动物），不会归入鱼或爬行动物。枚举分别由 `miniprogram/data/circles.js`、`topics.js`、`animal-types.js` 维护。

## 本轮内容与展示账号

知识卡从已核实的 ASPCA 资料中筛选，使用独立中文摘要；图片和视频采用逐项核实的 CC0 或 Public Domain 素材。包括知识卡配图和视频封面在内，本轮素材不要求公开署名，因此普通页面不再显示“资料整理”“授权图片”“作品来源”及摄影署名块。

原始文章、素材详情、作者和许可元数据、文件摘要、修改说明与复核记录继续保留。隐藏页面上的署名不等于删除来源证据，也不改变旧素材的许可。来源与维护规则见 [内容来源与维护](docs/07-内容来源与维护.md)，导入步骤见 [首批内容执行计划](docs/09-首批300条内容执行计划.md)。

六个内容账号使用自然昵称和原创头像：橘子与猫、奶盖喵、栗子汪汪、阿禾慢慢遛、毛球笔记、毛孩拾光。账号与真实用户分开管理，不计入真实用户和宠物统计；不编造养宠经历、原作者身份或互动热度。

旧目录撤下的知识及猫狗内容保存在 `content/batch-001/withdrawn-*.json`，原始素材不因撤下而删除。目录同步保留用户自己的账号、帖子、草稿和互动；已删除目录项不会因更新恢复。知识卡引用现有照片作封面，不增加图片内容的条目数。

```sh
npm run content:status
npm run content:validate
```

当前目录清单为 `content/batch-001/approved.json`，新采集材料在 `content/batch-002/`。构建目标读取清单的 `targets`，当前为 `{knowledge: 58, photo: 289, video: 13}`。`content:build` 要求数量与目标一致且全部审核通过；`content:publish` 允许不超过目标的非空小批清单。**两种命令均替换完整本机目录，清单必须包含所有仍要展示的条目。** 它们不会上传微信或写入云数据库。

附近地点和活动资讯维护于 `miniprogram/data/nearby-catalogue.js`，不走社区素材的构建清单。自动任务“上海宠物活动早晚更新”已启用，每天上海时间 09:00 / 18:00 检索全上海活动、查阅来源、去重并更新本地目录。首次有记录的早间监测于 2026-09-30 09:17 开始并已完成，新增复悦荟外广场宠物公园和申隆国庆勇士挑战，已重读活动的日期未发现变化；见 [首轮早间更新记录](output/nearby-research/2026-09-30-morning-update.md)。该流程不会自动把内容发布到微信线上；需接入云端资讯库，或重新上传、审核并发布包含新目录的小程序版本。

## 导入微信开发者工具

1. 导入项目根目录，即包含 `project.config.json` 的文件夹。
2. 使用该小程序管理员或已添加开发者的微信登录开发者工具。
3. 保持 `miniprogram/config.js` 的 `mode: 'demo'`，可先体验本机功能。
4. 更新后重新编译；无需为了刷新目录清除用户缓存。

本机模式的资料、媒体与操作只保存在当前浏览器或设备，不与其他人同步。本机创建的活动不代表已经对外开放报名。浏览器预览始终使用本机模式；站内通知也不是微信订阅推送。

原有虚构样例人物、帖子和活动已退出展示；设备中的历史样例归档与真实用户内容分开处理。首次互动会引导核验，旧 OpenID 或本机身份不会自动视为已核验。昵称公开，介绍、宠物资料和头像旁宠物展示分别受开关控制；原生活片区与核验信息不进入公共页面。附近宠友使用另外主动选择的公开活动片区，住宅距离还需独立开启。

## 接入真实多人使用

按 [初版使用与接入指南](docs/04-初版使用与接入指南.md)、[云开发接入说明](cloudfunctions/community/README.md) 和 [部署基础说明](infra/README.md) 接入，可先运行 `npm run release:plan` 查看缺项。

云端源码已实现业务和权限检查，但尚未部署。正式手机号核验、图片上传与用户视频上传都需要真实平台能力、配置及验证；本机成功不代表云端能力已开通。云端连接失败会显示错误，不会静默切回演示数据。

真实图片支持同步检查或带微信签名/AES 加密回调的异步检查，审核失败时不会发布。**用户视频云上传默认关闭，必须接入能审核完整视频及音轨的真实 provider；图片审核不能替代视频审核，仅填写环境变量也不能开启。** 视频暂限 60 秒、20 MiB，详见 [视频上传与审核接入](docs/video-upload.md)。人工复核的预置视频与用户上传审核能力分别管理。

图片托管地址、合法域名、云存储规则、真机媒体加载、多人互动与体验版上传仍需分别验收。当前没有完成云端内容发布或正式小程序发布。

## 检查与测试

```sh
npm run check
npm test
npm run content:validate
# 已安装微信开发者工具时：
npm run check:wechat
```

检查覆盖原生页面、权限、分类筛选、目录同步、审核回调、上传恢复、草稿隔离、视频文件校验及发布工具。SQLite 文件仅用于测试适配，生产仍使用 CloudBase。自动测试结果、编译结果与具体微信操作记录见 [功能验收记录](docs/06-功能验收记录.md)；以本次实际命令输出为准，不在此固定测试数量、目录版本或包体大小。

`check:wechat` 使用已安装开发者工具的 `wcc/wcsc` 检查模板和样式，不上传代码。非默认安装位置可用 `WECHAT_COMPILER_DIR` 指向 `wcc-exec` 目录。离线编译、浏览器预览和开发者工具模拟器均不能替代真机、真实云环境与微信接口验收。
