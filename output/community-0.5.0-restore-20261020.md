# 0.5.0 社区功能恢复 · 本地交付记录

日期：2026-10-20（北京时间）。依据用户要求恢复公共转发、公开发帖与聊天；保留私人日记和宠物私人资料的私密性。

## 恢复范围

- 当前源码版本为 0.5.0，固定 `productMode: 'community'`。首页保留动物和话题筛选，恢复发帖、关注、圈子、点赞、评论；底部恢复消息入口及好友、聊天、群聊页面。
- 首页、附近、公共地点/路线、活动、公开帖子、作者主页、圈子和视频页面恢复好友转发及朋友圈入口。分享使用公共静态封面，避免自动截图带出私人信息或草稿。
- 非公开帖子不显示分享菜单；作者使用“公开后分享”时需明确确认，仅更新选中的帖子。原有可见范围设置仍需作者主动选择。未放宽后端的身份核验、内容审核和访问检查。
- 私人日记、私人宠物资料及资料编辑页面继续禁止直接分享。已保存的作者主页按字段可见范围展示，草稿不会作为主页内容分享。

## 旧资料保护

- “我的 → 本机私人资料”提供当前本机账号原个人版日记、宠物资料、草稿的只读入口，不迁移、不公开。
- 资料库在页面隐藏、账号切换或读取失败时清空显示缓存；未关联的云账号不能读取旧本机资料。
- 社区草稿、上传和宠物附件清理限定账号与环境，保护私人命名空间和仍被其引用的照片、视频及草稿。
- 本轮浏览器验收未发送消息、发布帖子、删除真实数据或读取私人草稿正文。自动测试使用隔离测试数据。
