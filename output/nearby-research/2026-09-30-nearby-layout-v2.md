# 附近页布局第二版

2026-09-30，本地实现。用户授权按上一轮视觉诊断优化附近页。

## 改动

- 默认顶部收为地区与搜索、三栏导航、一行快捷筛选。地区与片区合并入口，更多筛选按需展开；搜索继续替换地区行。
- 好去处使用实景缩略图或明确的类别线条图形，突出名称、行政区/片区、最多两项玩法和携宠要点。完整介绍、规则、来源与图片许可保留在详情。
- 一起玩使用日期块，突出举办状态、场馆、时间与票务。月份预告不推断具体日期，往期仍明确标为已结束。
- 附近宠友保留宠物优先的信息结构，统一配色；空态区分未加入、已加入但无人、筛选无匹配，分别提供创建名片、刷新、清除筛选。
- 新增页面展示辅助模块 presentation.js。短文案与已核实的原规则状态/正文、原票务分别绑定；原目录内容变化后自动显示完整新文案，防止旧摘要覆盖更新。
- 保留独立地区状态、主动选距离参照、未知坐标不显示公里数、宠友公开字段和双向开启居住约距的规则。

未修改目录记录、用户资料、报名、账户或隐私开关。测试时临时选择中山公园为公开距离参照，完成后已通过界面清除。

## 验证

- `node --test tests/nearby-discovery.test.js tests/neighbor-pages.test.js tests/native-pages.test.js tests/nearby-detail.test.js`：48/48 通过。
- 两个附近测试文件新增面板开关/互斥、搜索取消/跨栏、宠友空态动作与旧请求失效回归。
- 独立执行展示辅助模块断言：原文改变或规则状态改变时摘要失效；票价更新立即回退新原文；月份预告保持日期待定；无条件字段的新记录可展示。
- `npm run check`：23 页面，主包 2040.8 KiB，social 分包 43.9 KiB（共享项目在本次检查时的状态）。
- `npm run check:wechat`：微信官方离线编译通过，23 WXML / 24 WXSS。
- 独立后台浏览器页验证地区/片区、带宠筛选、无搜索结果与取消、活动全上海独立范围、往期筛选、手选距离参照与公里数、宠友筛选空态、真实场景图片。浏览器警告/错误日志为空。
- 手选中山公园后，上海新国际博览中心场馆约距显示 14.1 km；其他无坐标记录未生成距离。
